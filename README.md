# PyPSA x SALib グローバル感度分析 (GSA) プロトタイプ

エネルギーシステム最適化モデル **PyPSA** と、感度分析ライブラリ **SALib** を結合し、技術コストや燃料費の不確実性がシステム総コストに与える影響を分析するプロトタイプ実装です。

---

## 📁 ディレクトリ構成

```text
.
├── gsa_prototype.py     # GSA実行メインスクリプト
├── requirements.txt     # pip パッケージ依存関係リスト
├── environment.yml      # conda 環境設定ファイル
└── README.md            # 本ドキュメント
```

---

## 🚀 環境構築方法

ご利用の環境（`pip` または `conda`）に合わせて以下のいずれかの手順でセットアップを行ってください。

### パターンA: `pip` を使用する場合

```bash
# 仮想環境の作成（任意）
python -m venv venv
source venv/bin/activate  # macOS/Linux
# venv\Scripts\activate   # Windows

# 依存パッケージのインストール
pip install -r requirements.txt
```

### パターンB: `conda` / `mamba` を使用する場合

```bash
# Conda環境の作成と有効化
conda env create -f environment.yml
conda activate pypsa-gsa
```

---

## 🏃 実行方法

セットアップ完了後、以下のコマンドでプロトタイプを実行します。

```bash
python gsa_prototype.py
```

実行が完了すると（約30秒〜1分）、以下が自動生成・出力されます：

1. **コンソール出力**: 各サンプルの計算進捗および **Sobol指標 ($S_1, S_T$)** の集計テーブル
2. **グラフ画像**: **`sobol_indices_prototype.png`** （各技術の感度指標を比較したバーチャート）

## 📊 モデル仕様

* **モデル構造**: 単一ノード（電力バス 1箇所）の容量拡張モデル
* **代表日サンプリング**: 1年（8760時間）から **5日おき・3時間解像度**（計584スナップショット）を抽出し、高速最適化を実現
* **構成技術（4コンポーネント）**:
  1. 太陽光発電 (`solar`): 可変費用 $0, 資本コスト不確実性
  2. 風力発電 (`wind`): 可変費用 $0, 資本コスト不確実性
  3. 定置型蓄電池 (`battery`): 6時間容量、可変費用 $0, 資本コスト不確実性
  4. ディーゼル発電 (`diesel`): 低資本コスト、高燃料費（可変費用不確実性）

---

## 📈 不確実性パラメータとGSA設定

| パラメータ名 | 対象技術 | 不確実性の範囲 | 変数名 (SALib) |
| :--- | :--- | :--- | :--- |
| 太陽光資本コスト | Solar | $\$35,000 \sim \$65,000$ / MW / 年 | `solar_cost` |
| 風力資本コスト | Wind | $\$56,000 \sim \$104,000$ / MW / 年 | `wind_cost` |
| 蓄電池資本コスト | Battery | $\$30,000 \sim \$90,000$ / MW / 年 | `battery_cost` |
| ディーゼル燃料費 | Diesel | $\$60 \sim \$140$ / MWh | `diesel_marginal_cost` |

* **サンプリング手法**: Saltelliサンプリング ($N=32$, 全256サンプル)
* **目的変数**: システム総コスト ($Y$)

---

## 🔍 指標の読み方

* **$S_1$ (第1次感度指数)**: 単独パラメータが直接システムコストに与える影響度（直接効果）
* **$S_T$ (総感度指数)**: 他のパラメータとの相乗効果（交互作用）を含めた総合的な影響度
* **$S_T - S_1 > 0$**: 値が大きいほど、他技術との組み合わせやシステム制約（相乗効果）によって大きく挙動が変化する「交互作用依存型」技術であることを示します。

## 🛠️ トラブルシューティング

* **ソルバーエラーが発生する場合**:
  `highspy` や `cbc` などのLPソルバーが利用可能か確認してください。PyPSAはデフォルトでScipy経由のソルバーやHiGHS、Cbcを自動選択します。
* **計算時間を変更したい場合**:
  `gsa_prototype.py` 内の `N = 32` を増減させることで、精度と計算時間のバランスを調整できます。
